# 网络、流程与物理图形

## 核对模型，再选择图形

从实现列出输入形状、每层操作、偏置、输出形状、共享参数、固定参数和损失路径。每个视觉层叠都能对应实际的门、时间或重复结构。

| 内容 | 有解释力的表达 |
|---|---|
| 物理域 | 真实几何的剖切、测区、边界或局部场；观测位置连到输入 |
| History | 时间轴、实际采样点、多通道曲线；逐时特征列与采样对应 |
| GRU | 重置/更新/候选三组权重，递归回路，末隐藏状态与维数 |
| Dense | 带权全连接、常数偏置入口，输入/输出维度 |
| Linear | 矩阵W、偏置b、`Wx+b`与维度 |
| GELU / sigmoid / tanh / ReLU | 对应激活曲线；横纵轴保持真实形状 |
| latent | 短向量或系数条，标明维度 |
| 耦合解码 | 一个共享潜变量进入各场行块或真实独立分支 |
| 残差相加 | 端口明确的圆形Σ节点 |
| 训练 | 损失、梯度/更新回路，必要时标出实际优化器 |

图中缩略的神经元、矩阵和场切片，在图注说明其采样或示意方式。Dense与Linear都可能是仿射层，按实际操作和用途命名。

## 路由

- 主干保持单向、连续，分支在共同的出点发出；汇合节点有独立入口。
- 圆形Σ的左右/上下端口按圆的几何边界求取。字形按其轮廓包围盒居中。
- 预留箭杆再画箭头，避免短距离只剩三角形。短内部连接可缩小箭头，而非把箭头放大。
- 直角路线用圆滑过渡。以一条连续路径绘制整条连接；不要拼接悬空线段。
- 线穿过分组边界时只在穿越处开口；到操作节点则终止在其边缘。
- 数据流实线、参数共享虚线、训练反馈点划线。转弯与标签错开，损失回路通常放到主干外侧。

`Plate.wire`使用二次Bézier圆角；`Plate.port`在组边框开口。层级为：分组底色、端口开口、主连线、操作节点、内部数据图形、文字。

## 权重图的真实结构

近白的矩阵可能反映零系数、极端值挤压动态范围、抽样遗漏或绘图错误。检查原始数组的分位数、组内最大值与输入列的变化，再决定表示方法。

可以显示完整矩阵、分组边界、固定/可训练身份及独立偏置。零值用可辨认的中性色。需提高结构对比度时使用明确的有符号平方根/asinh缩放，并在图注注明。用于数值比较的热图仍给真实色标与统一尺度。

## 可复用而非照搬

从Transformer借鉴残差路径、操作边界与重复结构；从SHPNet借鉴阶段分离、潜空间耦合和共享解码。按本方法的运算画图，不增添实现里没有的层。保留为读者解释数据来源的物理对象与时间维度。
