# 结构、流程与科学示意

## 先确定关系，再选择细节

明确图解释的对象、过程与尺度，从方法、代码、装置草图或用户提供的依据核对内容。先画主关系；只展开对读者理解有用的机制。结构层级可以是整套实验、算法阶段、单个模块或局部运算。

| 场景 | 需要解释的关系 | 可选表达 |
|---|---|---|
| 实验装置、检测链 | 空间位置、样品/束流、传感器、读出与控制 | 简化几何、剖面、测量方向、尺度标记、信号/控制连线 |
| 物理机制 | 状态、相互作用、边界条件、守恒或传输 | 物理对象、场/通量箭头、坐标、关键方程、局部放大 |
| 方法流程 | 输入、变换、判断、迭代与输出 | 阶段框、分支条件、循环、代表性中间结果 |
| 数据处理链 | 采集、校正、筛选、标定、重建或统计 | 数据形态、变换与单位、实际依赖、必要的不确定度入口 |
| 模型架构 | 张量、模块、共享/重复结构、融合与输出 | 模块层级、形状、计算操作、必要的训练/推理路径 |

投影、比例或几何经过简化时在图注标明。方框适合算法操作，物理对象可采用可辨认的功能图形；避免把所有对象都压成同一种框。已有SVG或适用的其他后端可以直接编辑。

## 布局与连接

- 主阅读方向稳定；并行、顺序和反馈关系从位置与连接读出。复杂内容可采用总览加局部、阶段分组或多个面板。
- 箭头的含义由本图定义：流体、能量、信号、数据或因果关系按实际情况表达。颜色之外用线型、标签或符号辅助区分。
- 连线在可辨认的边界或端口终止。分支有清楚的出点，汇合有清楚的语义；连线交叉与连接区别明确。
- 需要折线时用连续圆角路径，预留可见箭杆与标签空间。分组边界可以开口，具体操作节点则连接到边缘。
- 重复结构可用数量标记或一次展开加复用。共享模块的图形重复应与实际共享关系一致。

`Plate`提供毫米坐标、节点、端口和连续圆角线，适合需要精确控制的示意图。`Plate.wire`与`Plate.port`是可选实现；简单流程可以用更少的原生矢量对象完成。数据面板继续使用普通绘图轴。

实验示例见[光学透射测量](../examples/optical_schematic.py)：光源、分束、样品与双探测器采用原生矢量对象，区分光路和读出，展示基线归一化的透射率。器件位置为概念布局。

## 神经网络局部细节（按解释目的选择）

先核对输入输出、分支、参数共享和关键操作。总览图可以只显示模块与形状；解释模块内部机制时再选择下列图形。只画实际实现包含的结构。

| 操作或对象 | 有助于解释时可显示 |
|---|---|
| CNN / 卷积 | 感受野、核、通道与空间尺寸变化 |
| Attention / Transformer | Q/K/V、实际attention路径、头的组合、残差与归一化顺序 |
| GRU / LSTM / 时序模型 | 时间展开、门、递归状态；涉及权重时核对门的顺序 |
| Dense / Linear | 输入输出维度；需要时展示带权连接、矩阵、偏置或仿射式 |
| 非线性 / 归一化 / 池化 | 操作名、相关维度或实际响应曲线 |
| 多模态 / 多尺度 / 图网络 | 对应输入、消息传递、融合操作和输出 |
| 加法 / 拼接 / 加权融合 | 按实际操作使用Σ、concat或带权公式，避免含混的合流 |
| 优化与训练 | 仅在解释训练时显示损失、更新路径与固定/可训练身份 |

采用圆形Σ加法节点时，按字形轮廓居中，连接圆周端口；Σ适用于加法。矩阵热图、神经元、激活曲线与优化器标签由内容决定。采样矩阵或缩略神经元在图注说明其示意方式。

## 数值纹理与实际依据

权重、空间场、响应和信号使用真实数组或明确标记的演示数据。近白矩阵先检查零值、分位数、动态范围与抽样；显示结构可选有符号平方根/asinh等变换，并说明缩放规则。数值比较保持共同尺度、真实色标和单位。

现有`assets/approved-network-v19.png`与`examples/network.py`是具体架构案例，可以借鉴层级和连接处理。它们的分支数、门、配色、物理输入及训练回路由该案例决定。
