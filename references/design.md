# 科研图的共用设计

本页用于数据图、组合面板与结构示意。按当前任务采用有关部分；网络模块与端口规则见[结构示意](architecture.md)。

## 科学信息先于版式

先确定读者需要判断的关系：变化趋势、组间差异、分布、拟合质量、空间结构，或方法怎样工作。
图型跟随这个关系，保留数据的单位、采样结构和比较基准。数据图的选择与配方见[数据图](data-plots.md)。

- 一条曲线或一个比较可由单个绘图区完成时，直接使用原生绘图接口。
- 只有需要共同解释的证据才组成面板；把主要结果与对应诊断放在相邻位置。
- 结构示意按对象和关系组织；数据图按坐标、数据系列与比较组织。
- 保留用户已有的有效后端、图型和分析结论，针对实际问题调整表达。

## 从最终尺寸安排布局

先确定图在论文、报告或幻灯片中的最终宽度，再决定字号、面板数量和信息密度。
85 mm 单栏、183 mm 双栏可作为论文图的可调起点；项目模板、期刊当前要求和用户指定尺寸决定实际值。
高度由标签、图例、色条和数据形状共同决定；空间场与几何对象优先保留有意义的长宽比例。

| 项目 | 可调起点 |
|---|---|
| 轴标签与普通说明 | 7–9 pt |
| 数学表达 | 与相邻正文接近，按实际字形调整 |
| 数值刻度与图例 | 6.5–8 pt |
| 面板字母 | 8–10 pt，加粗，整组一致 |
| 数据曲线 | 0.8–1.4 pt |
| 轴线与辅助线 | 0.5–0.8 pt，辅助线更轻 |
| 数据标记 | 约3–5 pt，按点密度调整 |
| 相邻绘图区间距 | 从3–6 mm起，给标签和图例留足空间 |

这些数值用于开始排版。按最终尺寸观察后调整，检查上下标、误差棒端帽和细线是否仍可辨认。
优先减少重复标签、移开图例或调整面板结构，再考虑缩小字体。
使用 `figsize=(width_mm / 25.4, height_mm / 25.4)` 保持尺寸明确；裁切或排版缩放会改变实际成图尺寸。

## 字体与数学

字体选择优先遵循用户、项目模板与投稿要求。未指定时，默认 Arial 普通标签、Times New Roman 数学及数值刻度。
沿用已有图时先检查其字体约定；一次修改应保持整组图协调。

- 变量斜体，单位、元素名和描述性下标正体；向量、矩阵等符号沿用研究中的约定。
- 轴标签写清量与单位，例如 `Energy $E$ (keV)`；倍率写在轴或单位表达中。
- 小数位、有效数字和科学计数法服务于读数精度，同一比较组保持一致。
- 公式作为完整表达排版，检查上下标、乘号、负号和关系符的间距与基线。
- 复杂推导放在正文；图内保留理解坐标、计算或物理关系所需的表达。

`configure()` 用于新图的字体与基础配置，`apply_chart_style(ax)` 提供轴的轻量样式。
修改已经生成的图时，也要检查已有标签、图例和注释对象；全局配置不会自动重设所有现存对象。
运行字体检查核实实际字体与所需字形。缺字时明确选用可用字体或排版方案，保持同一表达协调。

## 视觉层级与可访问性

让数据或关键关系先进入视线，再读取标签，最后查阅辅助信息。留白用于区分比较组与阅读顺序。

- 白底、深色文字作为起点；网格、参考线和边框保持比数据安静。
- 同一方法、条件或物理量在整组图中使用稳定的颜色与名称。
- 定性类别使用可区分的离散色；顺序量使用单调亮度色图；有明确零中心的正负量可用发散色图。
- 颜色再配合标记、线型、直接标签或面板区分。检查灰度显示和常见色觉差异下的辨识度。
- 一种线型维持一种含义，例如实测、拟合或参考；同一条件跨图保持一致。
- 密集数据可使用透明度、分箱或适当统计表达，保留样本密度与离群值的含义。

深青与棕橙等现有配色可继续作为数据系列起点；颜色角色按研究内容确定。

## 图例、色条与标注

图例解释数据编码，色条解释数值映射，注释指出读者需要定位的事件或关系。
能在曲线末端清楚直接标注时，可减少往返查图例的负担。

- 图例放在空白区域或绘图区外，检查其是否遮挡数据、误差范围或参考线。
- 组合面板中真正相同的编码可共用图例；不同含义分别说明。
- 色条标量名、单位与适当刻度；共享色条要求相同归一化、范围和数据含义。
- 标注与目标保持明确对应；参考值、阈值或预测起点使用易辨认而克制的线和短标签。
- 面板字母、轴标签、图例与色条间距保持稳定；长单位和科学计数倍率也计入布局。
- 图注交代误差范围、独立单位与必要显示变换；图内放置支持读图的内容。

## 交付与检查

按用户需要导出 PNG、SVG、PDF 与生成源码。SVG 可保留活文字，PDF 可嵌入字体；检查实际导出结果。
保留原始数据、显示变换和必要的生成参数，方便重画与修改。
按[质量检查](quality.md)选择与当前图有关的检查层级；单图先核对数据、标签与成图，组合或复杂图再检查布局细节。
最终以实际使用尺寸查看，确认数据、文字、图例和色条完整且容易读取。
