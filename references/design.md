# 科研图的共用设计

本页用于数据图、组合面板与结构示意。按当前任务采用有关部分；网络模块与端口规则见[结构示意](architecture.md)。

## 科学信息先于版式

先确定读者需要判断的关系：变化趋势、组间差异、分布、拟合质量、空间结构，或方法怎样工作。
图型跟随这个关系，保留数据的单位、采样结构和比较基准。数据图的选择与配方见[数据图](data-plots.md)。

- 一条曲线或一个比较可由单个绘图区完成时，直接使用原生绘图接口。
- 只有需要共同解释的证据才组成面板；把主要结果与对应诊断放在相邻位置。
- 结构示意按对象和关系组织；数据图按坐标、数据系列与比较组织。
- 保留用户已有的有效后端、图型和分析结论，针对实际问题调整表达。

图的篇幅与它增加的理解相称。少量计数加一列机构标识，往往只是在重复正文。需要说明制度差异时，可让每个案例采用相同维度，以专业路径、职责、持续阶段和具体支持方式形成真正可比较的结构。用户已指定图型时尊重其要求，围绕读图目的调整内容密度。

## 从最终尺寸安排布局

先确定图在论文、报告或幻灯片中的最终宽度，再决定字号、面板数量和信息密度。
85 mm 单栏、183 mm 双栏可作为论文图的可调起点；项目模板、期刊当前要求和用户指定尺寸决定实际值。
高度由标签、图例、色条和数据形状共同决定；空间场与几何对象优先保留有意义的长宽比例。

先查实际模板。NeurIPS 2026与ICLR 2027的正文宽度均为139.7 mm，85/183 mm并非其栏宽。若输出宽度与插入宽度不同，最终字号等于源字号乘以两者宽度之比。例如183 mm图缩到139.7 mm，7 pt文字会变成约5.34 pt。让生成尺寸接近最终插入尺寸，减少排版时的整体缩放。[NeurIPS 2026模板](https://media.neurips.cc/Conferences/NeurIPS2026/Formatting_Instructions_For_NeurIPS_2026.zip)、[ICLR 2027模板](https://media.iclr.cc/Conferences/ICLR2027/iclr-2027-style-files.zip)

| 项目 | 可调起点 |
|---|---|
| 轴标签与普通说明 | 7–9 pt |
| 数学表达 | 与相邻正文接近，按实际字形调整 |
| 数值刻度与图例 | 6.5–8 pt |
| 面板字母 | 8–10 pt，加粗，整组一致 |
| 数据曲线 | 0.8–1.4 pt |
| 轴线与辅助线 | 0.5–0.8 pt，辅助线更轻 |
| 数据标记 | 约3–5 pt，按点密度调整 |
| 相邻绘图区间距 | 从3–6 mm起，给标签和图例留足空间 |

这些数值用于开始排版。按最终尺寸观察后调整，检查上下标、误差棒端帽和细线是否仍可辨认。
优先减少重复标签、移开图例或调整面板结构，再考虑缩小字体。
使用 `figsize=(width_mm / 25.4, height_mm / 25.4)` 保持尺寸明确；裁切或排版缩放会改变实际成图尺寸。

## 留白与阅读顺序

先按数据的形状安排绘图区，再给刻度、标签和必要图例留空间。曲线图的高度依据变化与误差范围决定；空间热图保留真实几何比例；少量类别的比较可用紧凑横条或点图。

- 标签、标记与所属对象靠近，比较组之间留更明显的间隔。
- 同一行面板对齐数据区和标题基线，同一列采用稳定的间距。真正共享的图例或色条只放一次。
- 图例、色条、标题和页面边缘之间避免层层堆积大间距。收紧空白时，仍给上下标、刻度倍率和误差棒端帽留足空间。
- 单图通常由数据区、坐标及必要图例构成。数据已经简单清楚时，把解释写入图注，避免另加侧栏、底部说明块或结论卡。
- 画布大小随内容调整。空白比例适合目视判断，保留由物理纵横比、轨迹范围和比较结构产生的空间。

## 图内标题与图注

图注在论文中说明实验设置、统计定义和主要阅读关系。单图主题已由图注表达时，通常省去图内总标题。

面板标题用于识别对象、方法或实验条件，例如“(a) Reference”或“(b) $d=128$”。保持同一组标题的字号、字重、基线、对齐方向及到数据区的距离一致，字母与短标题放在同一行。标题长度明显不同时，先压缩命名或将长解释移入图注。

数据图使用必要的短名和局部注释。仅在事件、阈值、异常或具体结构需要定位时添加说明，并贴近对应对象。避免叠加总标题、面板标题、副标题和解释段落，使读图从数据开始。

## 字体与数学

字体选择优先遵循用户、项目模板与投稿要求。未指定时，默认 Arial 普通标签、Times New Roman 数学及数值刻度。
沿用已有图时先检查其字体约定；一次修改应保持整组图协调。

中文文字占主体时，先看所属报告的正文与标题字体。宋体正文、黑体短标题等既有体系可直接用于文本型比较图；同一层级的短数字和标签保持协调。避免在一个短标签中频繁切换粗细悬殊的中西文字形。官方书法字标按独立图形处理，控制其尺寸与位置，使其清楚识别案例。

- 变量斜体，单位、元素名和描述性下标正体；向量、矩阵等符号沿用研究中的约定。
- 轴标签写清量与单位，例如 `Energy $E$ (keV)`；倍率写在轴或单位表达中。
- 小数位、有效数字和科学计数法服务于读数精度，同一比较组保持一致。
- 公式作为完整表达排版，检查上下标、乘号、负号和关系符的间距与基线。
- 复杂推导放在正文；图内保留理解坐标、计算或物理关系所需的表达。

`configure()` 用于新图的字体与基础配置，`apply_chart_style(ax)` 提供轴的轻量样式。
修改已经生成的图时，也要检查已有标签、图例和注释对象；全局配置不会自动重设所有现存对象。
运行字体检查核实实际字体与所需字形。缺字时明确选用可用字体或排版方案，保持同一表达协调。

## 视觉层级与可访问性

让数据或关键关系先进入视线，再读取标签，最后查阅辅助信息。留白用于区分比较组与阅读顺序。

- 白底、深色文字作为起点；网格、参考线和边框保持比数据安静。
- 同一方法、条件或物理量在整组图中使用稳定的颜色与名称。
- 定性类别使用可区分的离散色；顺序量使用单调亮度色图；有明确零中心的正负量可用发散色图。
- 颜色再配合标记、线型、直接标签或面板区分。检查灰度显示和常见色觉差异下的辨识度。
- 一种线型维持一种含义，例如实测、拟合或参考；同一条件跨图保持一致。
- 密集数据可使用透明度、分箱或适当统计表达，保留样本密度与离群值的含义。

深青与棕橙等现有配色可继续作为数据系列起点；颜色角色按研究内容确定。

### 配色与层次的实际选择

定性类别、顺序数值和有符号偏差分别选色。`get_palette()`提供几组具名的定性颜色，适用于少量可区分系列；`viridis`、`cividis`等顺序色图和零中心发散色图用于相应数值。颜色次序和数据含义一致，缺失值与低值分开表达。[Matplotlib色图说明](https://matplotlib.org/stable/users/explain/colors/colormaps.html)

| 数据角色 | 表达起点 |
|---|---|
| 主要观测或核心路径 | 较深、清楚的色，稳定的轮廓与必要标记 |
| 同等地位的比较组 | 互相可分、视觉权重接近的类别色，辅以线型或标记 |
| 参考或背景样本 | 可辨的中性灰或较弱颜色，保持其变化可读 |
| 误差范围或分布范围 | 较浅填充与清楚边界，中心估计置于前景 |
| 阈值、零线与网格 | 更轻的线宽和明度，必要时用虚线区别 |
| 局部重点 | 一种强调色或清楚轮廓，标记对应数据或算子 |

颜色的强弱服务于角色。所有类别同等重要时保持相近权重；强调某个结果时才建立前景与背景。普通容器可用白底和轻轮廓，关键节点或活动区域再使用更强填色。不同浅色框、同粗箭头和同黑文字铺满整图，容易使层次变平。

具名调色板的定义及适用条件来自原作者。优先选择足够的少量颜色，白底细线避免过浅颜色；增加系列时同时检查线型、标记及直接标签。[Okabe与Ito](https://jfly.uni-koeln.de/color/index.html)、[Paul Tol](https://sronpersonalpages.nl/~pault/)

从色板取色以后仍需看整图。同等条目已经由位置和直接标签区分时，可沿用一种协调主色；明度、线宽和局部强调提供进一步层次。图中出现不同机构的彩色徽标时，数据颜色应与这些现有颜色一起考虑，避免再叠加一套强烈的蓝、绿、洋红、黄。比较维度较多时，颜色稳定表示职责或对象，让每个面板沿用相同含义。

## 图例、色条与标注

图例解释数据编码，色条解释数值映射，注释指出读者需要定位的事件或关系。
能在曲线末端清楚直接标注时，可减少往返查图例的负担。

- 图例放在空白区域或绘图区外，检查其是否遮挡数据、误差范围或参考线。
- 组合面板中真正相同的编码可共用图例；不同含义分别说明。
- 色条标量名、单位与适当刻度；共享色条要求相同归一化、范围和数据含义。
- 标注与目标保持明确对应；参考值、阈值或预测起点使用易辨认而克制的线和短标签。
- 面板字母、轴标签、图例与色条间距保持稳定；长单位和科学计数倍率也计入布局。
- 图注交代误差范围、独立单位与必要显示变换；图内放置支持读图的内容。

## 官方标识与字标

机构身份有助于识别比较对象时，可把官方校徽、院徽或字标作为行标签或局部标注。优先采用官方SVG、EPS、AI、PDF，按标准比例、颜色和间距使用。官方书法字标按图形资产嵌入，普通图中文字继续采用约定字体。缺少原始字标时可正常排写机构名称，避免将近似字体标成官方字样。

保存下载页、原文件URL及来源文件。以矢量格式交付时检查资产中的实际路径、文字和嵌入位图，校徽及小字也要在最终尺寸下可辨。品牌手册有最小尺寸要求时按该标识核定。例如清华规定校徽最小直径9 mm，这一数值只对应清华标识。[清华校徽规范](https://vi.tsinghua.edu.cn/gk/xxbz/xh.htm)、[标准组合](https://vi.tsinghua.edu.cn/gk/xxbz/bzzh1.htm)

## 交付与检查

按用户需要导出 PNG、SVG、PDF 与生成源码。SVG 可保留活文字，PDF 可嵌入字体；检查实际导出结果。
保留原始数据、显示变换和必要的生成参数，方便重画与修改。
按[质量检查](quality.md)选择与当前图有关的检查层级；单图先核对数据、标签与成图，组合或复杂图再检查布局细节。
最终以实际使用尺寸查看，确认数据、文字、图例和色条完整且容易读取。
