# 科研数据图

先选择单图或组合面板，再按科学问题读取下面有关的配方。共用字体与尺寸见[设计规范](design.md)，检查按[质量检查](quality.md)执行。

## 单图：直接绘制

折线、散点、误差棒、直方图等普通图直接使用 `plt.subplots()`，保留现有数据接口和分析结果。
`configure()` 设置字体与基础样式，`apply_chart_style(ax)` 调整轴，`export()` 输出所需格式。
单图按坐标和数据安排内容；只有需要自由放置物理对象或结构关系时才使用 `Plate`。

```python
configure()
fig, ax = plt.subplots(figsize=(85 / 25.4, 58 / 25.4), layout="constrained")
ax.plot(x, y, label="Measurement")  # 使用当前任务的真实数组
ax.set(xlabel="Time $t$ (s)", ylabel="Signal $s$ (V)")
apply_chart_style(ax)
export(fig, "output/signal")
```

可运行入口：`python examples/simple_plot.py --out output`。单图完成后核对数据、标签、尺度与最终尺寸，按用户需要交付。

## 组合面板：围绕一个科学判断

主结果需要拟合诊断、多个条件或空间比较共同解释时，使用 `plt.subplots()`、`GridSpec` 或已有后端布局。
例如上方标定关系、下方残差；或并排参考场、预测场与误差场。各面板面积按证据作用分配。

- 只在量、单位和读数范围相容时共享坐标轴。
- 同类比较维持相同尺度、绘图区尺寸与色标；不同物理量分别表达。
- 使用布局引擎处理标签、图例和色条，再检查渲染后的绘图区。
- `check_axes_alignment()` 适用于要求同尺寸或同边缘的比较组；主图与较矮残差图等不同跨度分别安排。
- 沿用 `examples/data_plot.py` 可查看原生子图中的配对案例与时间曲线。

可运行科研配方：`python examples/scientific_plots.py --kind calibration --out output`。
`--kind` 可选 `calibration`、`spectrum`、`heatmap`、`distribution` 或 `all`。这些示例使用注明来源的演示数据，实际任务替换为研究数据。

## 选择配方

| 要回答的问题 | 起步表达 | 继续阅读 |
|---|---|---|
| 信号怎样随时间或自变量变化 | 曲线、观测点与有定义的误差范围 | 曲线与误差棒 |
| 两个量有什么关系，标定或拟合是否合适 | 散点、拟合与残差 | 散点、拟合与残差 |
| 事件集中在哪些区间，能峰位于哪里 | 阶梯计数谱或直方图 | 计数谱与直方图 |
| 分布和个体变化怎样，样本是否配对 | 原始点、分布与配对连线 | 分布与配对 |
| 空间形状、局部差异或矩阵数值怎样 | 带物理坐标的场图与色条 | 热图与空间场 |

## 数据与比较约定

- 确定每个点代表什么，以及独立单位、样本量、条件和配对关系。重复测量、不同种子与独立案例分别处理。
- 误差条或阴影区间注明是标准差、标准误、置信区间、预测区间还是测量不确定度，以及如何得到。
- 保留原始量、真实单位与信号尺度。转换后的变量与单位写在坐标或图注中。
- 平滑、分箱、插值、归一化和对数显示与源数据分开；参数和排除规则随生成代码保存。
- 缺失、未测和零值分别表达；对数轴遇到非正值时保留其处理记录及数量。
- 图型变化服务于科学问题，已有分析给出的拟合与统计结果随图保留。

## 曲线与误差棒

时间或有序自变量用曲线表达；离散观测可叠加标记。排序前核对时间与观测对应关系，缺失段保留断点。
连续线只连接有科学意义的相邻点；模型连续预测可独立画线。
少量测点常用误差棒，密集预测可用区间带；图例或图注写清区间定义。
标记采样位置、干预事件或预测起点，区分已观测时段与预测时段。
多组比较先统一单位与轴范围；局部放大使用清楚的范围标记。

## 散点、拟合与残差

散点保留观测位置、配对和测量不确定度。密集时用透明度或二维分箱，说明频数或密度含义。
拟合曲线使用现有分析结果，并标出使用区间；外推段与数据支持范围清楚区分。
选择拟合方法时考虑响应变量误差、异方差，以及自变量是否也有不可忽略的不确定度。
置信带与单次观测预测带分别命名，保持与所用模型一致。
标定例见 `--kind calibration`：主图显示测点和拟合，下方残差共用自变量。
残差定义如 `y - fit(x)` 写清符号与单位；标准化残差注明分母，并给出零参考线。
残差中保留趋势、异方差与异常点，避免只用拟合优度数字替代诊断。

## 计数谱与直方图

优先读取原有 bin 边界与计数，用阶梯表达保留分箱；有原始事件时依据测量分辨率与问题选择 bin。
区分 counts/bin、counts/keV、count rate 和概率密度，写清单位。不同 bin 宽度或曝光时长的比较采用相容归一化。
误差定义来自计数模型与数据处理；低计数时选择相应的区间或似然，背景扣除后传播信号与背景的不确定度。
拟合模型若表示计数期望，应与 bin 积分或约定的采样方式一致。
对数纵轴用于跨数量级读数，检查零计数的显示方式；净谱中的负值按分析含义保留。
谱图例见 `--kind spectrum`。峰位、拟合区和参考线只标当前分析需要的内容。

## 分布与配对

先确认独立单位与各组样本量。小样本优先直接显示观测点；箱线图、小提琴图或 ECDF 根据比较问题选用。
箱线图说明四分位、须与离群点的定义；小提琴图留意带宽与小样本密度形状。
同一对象的前后或方法比较用配对连线，必要时另画配对差值与零参考线。
仅有汇总量时明确其定义；已有原始数据可同时表达个体差异与中心/区间。
多种子结果与多独立案例结果使用不同分组或说明，保持推断单位清楚。
配方见 `--kind distribution`；抖动只帮助区分重合点，数值和配对关系保持原样。

## 热图与空间场

空间场保留真实坐标、方向、几何比例与边界。规则网格可用 `imshow` 并明确 extent/origin，不规则网格选择合适网格接口。
矩阵热图解释行列含义；排序、聚类或重排规则随图保留。
参考与预测共用归一化、范围和色条；误差场单独设色标，正负误差可围绕有意义的零值对称。
顺序量使用单调亮度色图；缺失区域单独编码，色条裁切或饱和范围用端标等方式表达。
插值、平滑与分辨率分别注明；比较细节时采用相同显示处理。
配方见 `--kind heatmap`。色条参与布局，核对每个比较场的实际绘图区与比例。
