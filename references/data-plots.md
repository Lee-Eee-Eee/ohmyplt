# 数据图

## 从科学问题选择图形

| 问题 | 合适的表达 |
|---|---|
| 同一案例上两方法差多少 | 配对点/线，或配对差值与零参考线 |
| 多种子或多独立案例的变化 | 单独点与明确的中心/区间；单位以独立案例定义 |
| 信号与预测随时间变化 | 对齐时间轴的曲线，标采样、预测起点与关键事件 |
| 空间形状和误差 | 保留几何的切片；同尺度参考/预测与独立误差色标 |
| 误差集中在哪些条件 | 分组、排序或连续关系，保持比较基线清楚 |
| 方法怎样工作 | 放到结构示意图，用真实输入、操作与输出解释 |

主图优先回答一个判断。诊断从属，避免按指标数量平均排满格子。标题和直接标签帮助比较；背景、网格和装饰退后。

## 比较与尺度

- 对同一组案例进行配对；保留每个独立案例或预先定义的汇总方式。
- 误差条注明其定义：跨案例、跨种子、标准差、置信区间或其他范围。种子变化与实际案例差异分别表达。
- 使用真实单位和信号量级。缩放、对数、归一化和插值有明确依据，源数据与显示变换分开。
- 比较场使用共同色标；正负误差适合零中心发散色图。顺序量采用单调亮度色图。
- 留下必要的参考线、采样点、分区和事件标记。刻度数量服从最终尺寸。

## 字体与布局

普通说明Arial，变量、单位表达与数值刻度Times New Roman。`apply_chart_style(ax)`设置该技能的基本风格；按数据选择范围、刻度和标签。

多面板用共享边缘、相同绘图区和稳定间距。色条、长标签或图例会挤压绘图区，检查渲染后的边界。可用`check_axes_alignment`比较重复面板的实际尺寸与边缘；不同跨度单独组成比较组。

## 可追溯输出

保留数据文件或生成入口、变量单位、显示变换和比较定义。导出后检查数据点、曲线、色标与标签都完整。图注交代读图所需的统计定义，后台检查记录不进入图内。
